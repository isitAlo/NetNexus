# NetNexus
A modular Python-based network tool for Linux designed for device discovery, ARP spoofing, and traffic shaping.

### Features
* **Live Discovery**: Background scanning for real-time updates.
* **Traffic Shaping**: Limit target bandwidth in **kbps**.
* **Connection Kill**: Instantly sever internet connection.
* **Auto-Cleanup**: Restores ARP tables and resets interfaces on exit.
